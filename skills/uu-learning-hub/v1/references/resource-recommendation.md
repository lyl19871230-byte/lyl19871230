# 推荐书 / 动画 / 学习资源工作流

## 核心规则

推荐不是“年龄4–5岁热门清单”，而是**当前能力匹配**。

## 流程

1. 读取UU最新正式能力画像；若没有可用画像，只为推荐所需能力做轻量问诊，不必启动完整七天计划评估。
2. B先检索项目来源文件：
   - 中文/阅读：绘本书单、教育部推荐、0–6书单、2–6岁书单、阿留阅读资料；
   - 英语：廖彩杏、亲子英语TPR、阿留英语路线及英语绘本；
   - 数学：指南、阿留数学规划、适龄数学资源；
   - 科学/动画：科学启蒙动画清单及相关科普资料；
   - 感统：3–6岁感统游戏清单。
3. 若项目资料不足、用户要“最新资源/当前可买/当前平台内容”，再查公开网络，并把项目来源与外部信息区分开。
4. 对候选资源做能力匹配：语言难度、认知跨度、兴趣、当前弱项、强项上限、家长执行成本。
5. 给出首选；必要时再给1–2个不同用途备选，不机械列10本。

## 推荐输出

每个首选至少说明：
- 为什么现在适合UU；
- 主要培养哪个能力；
- 怎么读/看/玩；
- 单次建议多久；
- 家长可以问什么；
- 不建议怎么使用；
- 太简单时下一档；
- 太难时降级档；
- 推荐依据来自哪个项目资料/外部来源。

## 能力不上封顶

年龄标签只是参考。若UU某能力明显高于一年级/同龄，可推荐更高阶资源；若某能力基础弱，也允许采用低龄但更合适的资源。**强项向上，弱项补底，不按统一年级锁死。**
