# 新鲜事工作流

## 目的

让UU产生“为什么、怎么回事、我能不能试试”，而不是背新闻。

## 选题优先级

第一梯队：科学、宇宙、航天、天体、AI/机器人、工程原理、机械、自然、深海、人体、生命、材料、能源。  
第二梯队：经济学启蒙、社会运行、历史文明、信息判断、概率与风险、发明创造。  
政治、国际关系、军事形势后置；若以后进入，采用适龄、事实性、背景与机制解释，不灌输政治立场，不用刺激性冲突细节。

## 必须先搜索

“最近/现在/本周/最新”的内容具有时效性，必须先检索近期可靠来源。优先原始机构、大学、研究机构、NASA/ESA等官方组织、原始研究和可靠新闻机构。

## 固定讲法

1. **先讲常识**：只给理解新闻必须知道的1–2个概念，用5岁语言、生活比喻、玩具/动作解释。
2. **再讲新闻**：只讲最核心的真实事实。
3. **一个原理**：一次只解释一个机制。
4. **让UU猜**：优先“为什么/如果/怎么证明/还有别的可能吗”。
5. **实验或游戏**：家里5–10分钟能完成，必要时注明安全事项。
6. **留问题**：不要一次讲光，留下一个下一步可追问的问题。

术语规则：先用儿童语言理解，再告诉正式名称。不要先给术语让孩子背定义。

## 筛选标准

真实 + 最近 + 儿童友好 + 有原理 + 能追问 + 最好可操作。

默认回避血腥灾难、成人犯罪、战争伤亡细节、纯娱乐八卦、与5岁理解无关的复杂政治争论。

## 新鲜事也可反哺三科

- 中文：新词、复述、原因、标题、反驳；
- 英语：只抽取1–2个当前水平可承受的真实表达；
- 数学：数量、比较、路线、测量、估计、图形；
- 但不得为了跨学科硬塞内容。
