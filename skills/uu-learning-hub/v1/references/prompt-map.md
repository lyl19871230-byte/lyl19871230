# 个人提示词库映射

本文件只保存V1确定的“用途映射”，运行时A仍应检索用户最新的《提示词分类整理大全（随时更新）》；未来提示词变化进入新版本，不改V1。

## Skill与调度骨架

- C038：把反复需求澄清与计划流程固化成技能。
- C092：多Agent/子代理任务委托；有真实委派工具时使用。
- C093：代理消息清晰可读。
- C064：检查Skill/agents指令的冲突、重复、无意限制。
- C094：按改动规模做有意义的验证。

## 七天计划主链

- C057：前置问诊。
- C061：先问问题判断水平；一次一个概念；根据反馈换解释并逐步加难。
- C024：深度理解验真，区分理解与死记。
- C025：错误后的核心逻辑溯源。
- C020：已有目标、期限、基础后生成7天路径与完成标准。
- C007：会了跳过/升级，不稳则放慢与复习。
- C048：一年→半年→月→周→日反向计划。
- C059：质疑计划，找假设、风险、缺失信息、失败原因。
- C062：需要时以多专业视角审查。
- C090：最终自我纠错与检查。

## 儿童化教学方法池

- C049：多维转换——字↔词↔句；数↔实物↔图↔故事；英语↔动作↔场景。
- C050：儿童版“反驳爸爸”找逻辑错误。
- C051：换角度、多方案。
- C052：一句话说核心。
- C053：词→句→小故事的分层表达。
- C054：学以致用，落到生活任务。
- C055：用熟悉生活类比抽象概念。
- C056：再想一种办法/更好的解释。
- C018：错误时至少给自主发现与修正机会，不立即揭晓。

## 英语专用

C079–C083整组：
- 真实交流与实际理解；
- 系统语言路线；
- 每日词汇/造句/发音/短练习；
- 语法放进日常对话；
- 对口语/写作做自然纠错。

对5岁儿童不做语法讲座；优先自然重述（recast）和真实场景。

## 不应机械调用

提示词编号是方法库，不是仪式。每次只选对当前问题真正有用的组合；重复方法合并。成人版措辞必须转译为5岁儿童可执行活动。
