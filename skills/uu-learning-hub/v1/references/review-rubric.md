# E课程审查量表

发布七天计划前必须逐项检查。任一“硬失败”出现即退回修改。

| 维度 | 通过条件 | 硬失败例子 |
|---|---|---|
| 连续性 | 明确继承上一周稳定/半会/未掌握/回访项 | 每周重新随机开始 |
| 记忆规律 | 核心新知有D0→D1/D2→D4→D7→后续周变式提取 | 只学一次或一天刷十遍 |
| 系统性 | 新知建立在已有能力上 | 基础未稳直接跳高阶 |
| 负荷 | 新增量与孩子表现相称 | 一次塞太多；或熟练后长期不升级 |
| 上限保护 | 强项持续提高复杂度/抽象度/多条件/多解 | 已超一年级仍只做低难重复 |
| 基础保护 | 弱项换实物/图/动作/故事/场景多向巩固 | 为赶进度跳过断点 |
| 真实掌握 | 至少有解释、变式、迁移、找错或反向出题 | 只看是否答对原题 |
| 中文结构 | 识字与词句/阅读/表达/拼音准备等形成主线 | 只刷识字卡 |
| 英语结构 | 听力/生活交流/TPR/词块/简单输出逐步形成 | 只有TPR或单词表 |
| 数学结构 | 数感+运算意义+图形空间+规律/测量/逻辑轮换 | 只有口算 |
| 兴趣适龄 | 操作、故事、游戏、选择、探究占重要位置 | 整周小学卷子化 |
| 周目标 | 可在周末明确判断是否达成 | “提升能力”这类无法验证目标 |
| 年度对齐 | 本周能说明对长期能力图的贡献 | 随机好玩但无累积 |
| 来源纪律 | 区分文件依据、教育推断、外部实时资料 | 把书单当科学结论 |

## E输出

- PASS：全部硬规则通过，可生成最终交付物。
- REVISE：指出具体维度、风险、需要D/F修改什么；修改后重新审查。
- 不允许用“总体不错”替代审查结论。

## 版本V1的已知基线失败（用于回归测试）

1. 曾在“生成七天计划”时直接产出Excel，跳过独立正式评估。V1必须阻止。
2. 曾在讲“新鲜事”时先报新闻、后补基础常识。V1必须改为先常识后新闻。
3. 通用资源推荐容易退化成按年龄/热门度列清单。V1必须使用当前能力画像匹配。
