# 悠悠学习：单日 / 七天学习计划 / 新鲜事 / 推荐书（当前正式版 V4）

## 总原则
- 基础不跳级，能力不上封顶。
- 已有信息足够时直接执行，不为流程重复确认。
- 只有缺失信息会实质改变难度、事实正确性、安全结果或外部持久化写入时才提问。
- 某个非关键工具、缓存或子代理不可用时，自动降级继续执行。
- 测试数据或用户明确说“不记录”的数据不得进入正式能力画像。

## 模式路由

### 学习计划模式
以下都属于同一个七日连续学习系统：
- “七天学习计划 / 一周学习计划”
- “今天的学习计划 / 今日学习计划”
- “下一天 / 继续一天 / 学习日N”

默认角色链：**C → A → B → D → F → E → Controller**

单日请求只输出当前七日链中的“下一个学习日”，**不重新启动一周，也不跳过C/A/B/D/F/E**。

若环境支持真实子代理，优先实际委派；若不支持，则主Agent按相同顺序串行承担角色，不需要再次征求用户同意，也不得声称启动了不存在的独立Agent。

### 新鲜事
默认轻量链：**B → F → E-lite**

### 推荐
默认轻量链：**C-lite（仅能力信息不足时）→ B → E-lite**

用户明确写“无需多代理即可”时，使用单Agent执行当前模式，但保持同等质量门禁。

## 测试模式
用户明确说明“测试 / 不记录”时：
- 可以完整运行C/A/B/D/F/E/Controller以测试流程；
- 测试结果不写入正式能力画像；
- 不计入正式学习日1/7；
- 不影响以后正式基线；
- 若测试的是学习计划输出，仍按正式交付格式生成Excel，但文件明确标记“测试版”。

## 学习计划流程

### 1. 读取已有状态
优先读取：
- 当前周已经完成几个学习日；
- 最新正式能力画像；
- 上一周项目总结（若存在）：稳定项、临界项、弱项、挑战项、全部题目、周测、家长观察。

没有上一周数据不阻断任务。

### 2. C做能力充分性检查
目标不是“必须提问”，而是判断现有正式数据是否足够决定当前学习日/本周内容。
- 数据足够：直接确认能力画像并继续。
- 少数关键未知：只问会改变课程设计的最少问题。
- 无可靠正式数据：做2–4轮自适应评估。
- 强项继续上探边界；弱项向下找真正断点。

### 3. A选择方法
从用户提示词库选择当前真正需要的方法，不机械全量调用。

### 4. B检索来源
1. 搜索当前Project/Library中最新可用的 `UU来源原始资料缓存_vN`；
2. 缓存不可访问/缺失/失败时，直接回原始项目来源；
3. 精确数字、图表、时间轴、原话、OCR异常、来源冲突时回原文件；
4. 最新公开事实才使用外部可靠来源。

### 5. D设计课程
- 上周/前日弱项必须被处理：继续、降级、换表征或暂缓并说明原因；
- 临界项安排变式提取；
- 稳定项合理降频或升级；
- 挑战项继续上探；
- 复习链参考 D0 → D1/D2 → D4 → D7 → 后续周；
- 负荷参考新知30%、复习迁移50%、挑战20%；
- 难度参考70%独立、20%提示、10%挑战；
- 中文、英语、数学保持独立主线。

### 6. F增加拓展
少量加入能激发“为什么”的问题/小游戏，不抢主课程时间。

### 7. E发布审查
逐日逐题审查：
- 连续性与系统性
- 题目逻辑与表述清晰
- 难度与真假掌握
- 英语生活化
- 三科结构
- 家长可执行性
- 上一周/前一学习日继承
- 当日和周目标可验证

单项允许 `N/A`；最终只允许 **PASS** 或 **REVISE**。

### 8. Controller输出Excel
E PASS后，**学习计划的正式交付物必须是 .xlsx，不能只在聊天中给题目。**

#### 单日学习计划
输出一个当天Excel，例如：
`UU学习日03_学习计划.xlsx`

至少包含：
1. 今日总览
2. 今日详细课表
3. 家长记录
4. 日闭环研判

其中“今日详细课表”至少包含：
- 科目
- 建议时间
- 能力目标
- 旧/新/挑战属性
- 活动ID
- 故事/游戏引入
- 家长可直接照读的话术
- 孩子动作/任务
- 具体题目
- 参考答案或判断标准
- 提示阶梯
- 常见错误与家长回应
- 方法/提示词代码
- 来源/证据
- 完成标准
- 积分
- 下次复习点

“家长记录”和“日闭环研判”预留UU实际回答、提示情况、表现状态和下一日处理字段。

#### 七天学习计划
输出完整周Excel，至少包含：
1. 本周总览
2. 上周继承与本周变化
3. 七天详细课程
4. 复习链
5. 惊喜挑战 / 前沿拓展
6. 家长记录
7. 周测
8. 下周决策
9. E审查摘要

聊天回复可做简要说明，但Excel是学习计划的正式交付物。

## 一天和一周的闭环
本Skill不按现实日期判断学习周。

- **一天闭环**：当天正式题目/任务已生成，UU完成回答或执行，并完成结果记录与当日研判。
- **一周闭环**：累计完成7个学习日闭环。
- 第7个学习日闭环后必须生成《UU本周学习项目总结》。
- 未执行内容标记“未观察/未提供”，不虚构。

## 每周项目总结
一周闭环后整理：
- 本周全部正式题目
- UU关键回答
- 每题/每类任务表现
- 三科最新能力画像
- 稳定项、临界项、弱项、挑战项
- 下一周继承项
- 家长观察

生成总结内容属于Skill职责；写入GitHub、覆盖外部文件、创建目录、提交commit等外部持久化操作需要用户当前任务明确授权。

## 英语生活化
英语课程服务真实生活交流。可复用已学生活词汇和简单句，也可在负荷允许时新增；不得为了形式强行增加新句型。TPR只是方法之一。

## 新鲜事模式
时间敏感内容必须查可靠公开来源。
固定结构：
**旧经验 → 必要常识 → 新闻事实 → 一个核心原理 → 猜想 → 怎么验证 → 小实验/小游戏 → 留一个问题**

## 推荐模式
读取最新正式能力画像；数据足够时直接推荐，不重复评估。优先项目来源，必要时使用外部最新资料。
