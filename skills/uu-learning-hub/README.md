# uu-learning-hub

正文名称：**悠悠学习：单日 / 七天学习计划 / 新鲜事 / 推荐书**

当前正式版本：**V5**

## 当前执行入口
- 当前Skill：`SKILL.md`
- 当前Agent规则：`AGENTS.md`
- 当前references：`references/`
- 当前验收测试：`tests/acceptance.md`
- V5历史快照：`v5/`

## 历史版本
- `v1/`、`v2/`、`v3/`、`v4/`：冻结历史档案
- `v5/`：当前版本核心快照

当前可执行入口只有根级 `SKILL.md`。

## 触发语
- `uu七天学习计划`
- `今天的学习计划`
- `下一天 / 继续一天`
- `新鲜事`
- `推荐`

“今天/下一天”属于七日连续学习系统，只输出下一个学习日，不重新开周。

## V5核心能力
- 单日和七天计划统一走C→A→B→D→F→E→Controller
- 单日E PASS后必须输出Excel
- 测试版也按相同格式输出Excel但不污染正式状态
- C使用明确的中文/英语/数学能力评估地图
- D遵守三科长期能力主线，防止中文只剩识字、英语只剩TPR、数学只剩计算
- 普通学习日默认约30分钟；明确加长/周末版可约60分钟
- 第7学习日周测重点验证变式、迁移、解释和应用
- 下周升级/复习/降难由能力证据决定
- 7个“任务→回答/执行→记录→研判”闭环后生成周总结

## 版本原则
历史版本不修改。后续规则变化创建V6、V7……
