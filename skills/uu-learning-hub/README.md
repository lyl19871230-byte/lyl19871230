# uu-learning-hub

正文名称：**悠悠学习：七天学习计划 / 新鲜事 / 推荐书**

当前正式版本：**V2**

## 入口

- 项目说明：`agent.md`
- 当前Skill：`v2/SKILL.md`
- V2变更说明：`v2/CHANGELOG.md`
- 历史V1：`v1/`（冻结，不修改）

## 版本原则

- 历史版本创建完成后不得修改、覆盖或删除。
- 提示词、来源、评估逻辑、课程规则或工作流有更新时，新建 `v3/`、`v4/`……
- 根级 `README.md` 和 `agent.md` 可作为当前项目说明与当前版本入口更新。
- 历史版本目录保持原始内容不变。

## 触发语

默认识别以下及其自然同义表达：

- `uu七天学习计划`
- `新鲜事`
- `推荐`

默认采用多代理协作模式。若用户明确写 **“无需多代理即可”**，则使用单代理执行，但仍需遵守当前版本的质量门禁。

## V2核心变化

V2新增：

- B代理优先调用来源原始资料缓存；
- 来源更新采用“相同保留，不同增加”；
- E代理增加连续性、系统性、题目逻辑、表述清晰和英语生活化硬审查；
- 每周生成UU学习项目总结；
- 保存一周全部题目和UU关键回答；
- 下一周C/D/E必须读取上一周总结；
- 正式Excel增加“上周继承与本周变化”；
- 建立周与周之间的长期连续学习闭环。

> Skill不硬编码某一次评估结果。每次正式运行以最新正式能力画像、上一周项目总结、周测和当前来源资料为准。
