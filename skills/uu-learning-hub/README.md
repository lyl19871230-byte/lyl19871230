# uu-learning-hub

正文名称：**悠悠学习：七天学习计划 / 新鲜事 / 推荐书**

这是悠悠学习项目的可复用 Skill 包。

## 版本原则

- `v1/` 是第一版冻结档案。**创建完成后不得修改、覆盖或删除其中任何文件。**
- 后续提示词、来源文件、评估逻辑、课程规则或工作流有更新时，新建 `v2/`、`v3/`……。
- 新版本应从上一版复制后修改，并在新版本中记录变化；旧版本保持字节级不动。
- 若需要“当前版”指针，只修改本 README 或另建 `CURRENT.md`，不要修改历史版本目录。

## 触发语

默认识别以下及其自然同义表达：
- `uu七天学习计划`
- `新鲜事`
- `推荐`

例如“生成UU一周计划”“最近有什么适合UU的新鲜事”“给UU推荐一本数学书/一部动画”等。

默认采用多代理协作模式。若用户在请求末尾明确写 **“无需多代理即可”**，则改为单代理执行，但仍需遵守该模式对应的质量规则和审查要求。

> 注意：Skill 不硬编码某一次评估结果。每次使用以最新正式评估、上一周周测和当前项目资料为准。
