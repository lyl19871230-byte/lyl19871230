## 当前执行入口
- 当前Skill：`SKILL.md`
- 当前Agent规则：`AGENTS.md`
- 当前references：`references/`
- 当前验收测试：`tests/acceptance.md`
- V4历史快照：`v4/`

## 历史版本
- `v1/`：冻结
- `v2/`：冻结
- `v3/`：冻结
- `v4/`：当前版本快照，使用 `SKILL.snapshot.md`

当前可执行入口只有根级 `SKILL.md`。

## 触发语
- `uu七天学习计划`
- `今天的学习计划`
- `下一天 / 继续一天`
- `新鲜事`
- `推荐`

“今天/下一天”属于七日连续学习系统，只输出下一个学习日，不重新开周。

## V4核心变化
- 明确单日计划也是七天学习系统的一部分
- 单日计划必须读取当前周和上一学习日状态
- 单日也运行C→A→B→D→F→E→Controller
- **单日计划E PASS后必须生成Excel，不能只在聊天中列题**
- 单日Excel固定包含今日总览、今日详细课表、家长记录、日闭环研判
- 测试模式也生成Excel验证最终形态，但不污染正式数据
- 一天闭环更新为“任务→回答/执行→记录→研判”
- 七个学习日闭环后生成周总结

## 版本原则
历史版本不修改。后续规则变化创建V5、V6……
