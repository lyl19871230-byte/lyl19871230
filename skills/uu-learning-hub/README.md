# uu-learning-hub

正文名称：**悠悠学习：七天学习计划 / 新鲜事 / 推荐书**

当前正式版本：**V3**

## 当前执行入口

- 当前Skill：`SKILL.md`
- 当前Agent规则：`AGENTS.md`
- 当前references：`references/`
- 当前验收测试：`tests/acceptance.md`
- V3历史快照：`v3/`

## 历史版本

- `v1/`：第一版冻结档案，不修改
- `v2/`：第二版冻结档案，不修改
- `v3/`：当前版本快照；使用 `SKILL.snapshot.md`，避免被重复注册为活动Skill

> 当前可执行入口只有根级 `SKILL.md`。历史版本仅用于审计、回溯和比较，不作为当前执行入口。

## 触发语

默认识别以下及自然同义表达：

- `uu七天学习计划`
- `新鲜事`
- `推荐`

用户明确写 **“无需多代理即可”** 时，使用单Agent执行；否则按当前模式选择最合适的多角色流程。

## V3核心变化

- 新增标准根级 `SKILL.md` 和 `AGENTS.md`
- 信息足够时自主推进，不为流程重复确认
- 无真实子代理时自动降级为单Agent串行角色
- 正式计划先做“能力充分性检查”，不是机械重复评估
- 新鲜事、推荐使用轻量角色链，不强制完整七天计划流程
- references按模式加载
- 来源缓存失败时自动回原始项目文件
- E单项支持N/A，最终仍只PASS/REVISE
- 上周弱项必须被处理，但允许继续、降级、换表征或暂缓说明
- 英语生活化不等于每周强制增加新词新句
- 明确外部持久化写入需要当前任务授权
- **学习周不按现实日期计算：完成1个“出题→回答/执行→记录”的学习日闭环算1天，累计7天即算1周；第7天闭环后必须生成周总结**

## 版本原则

- V1/V2原始内容保持冻结
- 后续规则变化继续创建V4、V5……
- 当前执行文件位于根级，历史版本使用snapshot命名避免重复Skill注册
- 测试数据不得污染正式能力画像
