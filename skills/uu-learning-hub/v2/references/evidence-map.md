# V2来源与缓存规则

## 默认查询顺序

1. 来源原始资料缓存
2. 原始项目文件
3. 外部实时公开来源（仅在需要最新信息或项目资料不足时）

## 原始资料缓存

缓存用途：
- 快速检索
- 页码/主题定位
- 避免每次重复读取全部PDF

缓存不得：
- 改写
- 补充
- 删减
- 自动纠错
- 把教育推断写成原始资料

## 必须回原文件的情况

- 精确数字
- 表格
- 图表/时间轴
- 原话引用
- OCR异常
- 来源冲突
- 缓存不足

## 增量更新

原则：

> 相同的保留，不同的增加。

文件指纹相同：保留旧缓存。  
文件变化：进入新缓存版本。  
新增文件：只追加新来源。  
历史版本不覆盖。
