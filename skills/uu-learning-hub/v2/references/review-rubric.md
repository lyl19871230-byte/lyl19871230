# V2 E课程审查量表

任一硬失败出现即 REVISE。

| 维度 | 通过条件 | 硬失败例子 |
|---|---|---|
| 日内连续性 | 每天承接前一天或明确属于同一能力链 | 每天随机换主题 |
| 周间连续性 | 承接上周弱项/临界项/挑战项 | 上周不会内容无理由消失 |
| 系统性 | 三科都有清晰能力主线 | 只有零散题 |
| 复习链 | 核心新知有D0→D1/D2→D4→D7→后续周 | 只学一次 |
| 题目逻辑 | 条件、答案、推理链成立 | 条件矛盾、开放题当唯一答案 |
| 表述清晰 | 家长可直接读，UU能理解任务 | 句子过长、代词不清、成人测试语言 |
| 英语生活化 | 来源基础上有生活词汇、简单句、家庭场景 | 整周只有TPR |
| 难度 | 强项上探、弱项补底 | 已会内容长期低难重复 |
| 真假掌握 | 有解释、变式、迁移、找错、反向出题等 | 只看原题答对 |
| 三科结构 | 中文/英语/数学长期结构完整 | 某科长期退化单一题型 |
| 家长可执行 | 材料、话术、提示、错误处理、停止条件清楚 | 家长拿到仍不知道怎么做 |
| 周目标 | 周末可明确验证 | 只有“提升能力” |
| 上周题目对比 | 必要复习或有价值变式 | 只换数字/角色的机械重复 |

## E最终五问

1. 前后连不连？
2. 学习有没有系统？
3. 题目本身对不对、清不清楚？
4. 这一周是否真正继承了上一周？
5. UU做完以后是否真的比周初前进了一步？

任一明显不成立：REVISE。

REVISE必须指出：哪一天、哪一科、哪一道题/活动、问题、原因、修改方向。
