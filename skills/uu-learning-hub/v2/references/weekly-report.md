# V2每周项目总结协议

每周执行结束后必须生成《UU本周学习项目总结》。

## 必须保存

### 1. 本周所有题目
- 中文题
- 英语词汇/指令/句子/问答
- 数学题
- 逻辑题
- 开放题
- 找错题
- 反向出题
- 挑战题
- 新鲜事探究题
- 周测题

### 2. UU真实表现
建议状态：
- 独立稳定完成
- 独立完成但较慢
- 答对但解释不清
- 提示后完成
- 实物帮助后完成
- 换情境后不会
- 答错后自行修正
- 多次仍不会
- 拒绝/疲劳导致无效数据
- 未测试

有价值的UU原话应保留。

### 3. 最新能力画像

中文：识字、词句、阅读/听故事、复述、因果、预测、逻辑、故事创造、语音意识、拼音/书写准备。

英语：已听懂词汇、生活句、指令、模仿、主动表达、是否仍需实物/动作、新场景迁移。

数学：数感、分合、运算意义、两步关系、图形空间、规律、时间、测量、条件推理、信息充分、多解、反向出题、数学表达。

### 4. 下一周继承项
- 稳定项：降频/升级/综合应用
- 临界项：必须再次出现并换情境
- 弱项：核心补强，多表征训练
- 挑战项：继续上探

## 建议目录

```text
weekly-reports/
└── YYYY-Www/
    ├── weekly-summary.md
    ├── question-bank.md
    ├── ability-profile.md
    └── parent-observations.md
```

历史周总结不覆盖；错误通过修订说明更正。
