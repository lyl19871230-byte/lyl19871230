# 三科长期能力主线（V5）

## 中文
长期主线包括：
- 识字兴趣与稳定识字
- 字→词→句→故事/阅读→表达→迁移
- 听故事、阅读理解
- 复述
- 因果
- 预测
- 逻辑错误
- 观点与理由
- 多种可能
- 故事创造
- 语音意识
- 拼音准备
- 书写准备
- 儿童诗、童谣、谜语、古诗等文化输入

不要把中文退化为单纯识字量训练。

## 英语
主线：
**听见 → 理解 → 实物/动作 → 高频生活词汇 → 简单生活句 → 场景问答 → 模仿 → 主动表达 → 阅读准备**

TPR只是方法之一。纠错优先自然重述，不讲抽象语法，不使用中文谐音记忆。

## 数学
长期覆盖：
- 数感
- 数量对应
- 比较、分类、排序
- 规律
- 分合
- 加减意义
- 图形与空间
- 对称、路线、方向
- 测量、估计
- 时间、钱币
- 数据
- 条件推理
- 信息充分性
- 开放题
- 多解
- 反向出题
- 数学表达
- 建模

强项可继续上探：多条件、多步骤、抽象、组合、解释、建模、简单乘法意义、初步概率等；不以年龄压住上限。

## 默认时长
- 普通单个学习日：约30分钟，中文/英语/数学各约10分钟。
- 用户明确要求加长、周末版或60分钟版：可扩展到各约20分钟。
- 时间是上限参考；达到目标或出现明显疲劳可提前结束。

## 复习与难度
- 新知/复习迁移/挑战参考约30/50/20。
- 难度参考约70%独立、20%少量提示、10%挑战。
- 间隔复习参考 D0 → D1/D2 → D4 → D7 → 后续周。

## 活动ID
正式计划建议统一：
- 中文 C001…
- 英语 E001…
- 数学 M001…

## 积分
积分主要奖励：
- 解释理由
- 找出错误
- 第二种办法
- 好问题
- 自我修正
- 挑战尝试

不要只按“答对数量”发分，也不要靠重复简单题刷分。
