# 学习计划Excel输出规范（V5）

## 总规则
学习计划经E PASS后，正式交付物必须为 `.xlsx`。聊天文字只能作为摘要，不能替代Excel。

测试模式也生成相同结构的Excel，但必须在文件名和工作簿显著位置标记“测试版”，且不写入正式学习状态。

## 单日学习计划Excel

建议文件名：
- 正式：`UU学习日03_学习计划.xlsx`
- 测试：`UU学习日_测试版.xlsx`

至少包含4张工作表：

### 1. 今日总览
至少包含：
- 当前学习日序号（如3/7）
- 测试/正式状态
- C能力定位摘要
- 今日三科目标
- 上一学习日继承项
- 今日新内容
- 今日挑战内容
- E审查结论

### 2. 今日详细课表
每个活动/题目至少包含：
- 科目
- 建议时间
- 能力目标
- 旧/新/挑战
- 活动ID
- 故事或游戏引入
- 家长可直接照读的话术
- 孩子动作/任务
- 具体题目
- 参考答案或判断标准
- 提示阶梯
- 常见错误与家长回应
- 方法/提示词代码
- 来源/证据
- 完成标准
- 积分
- 下次复习点

开放题不得伪造唯一答案；应写“合理答案范围/判断标准”。

### 3. 家长记录
至少预留：
- 活动ID/题号
- UU原话或实际表现
- 是否独立
- 使用了第几级提示
- 是否自我修正
- 兴趣/抵触
- 家长备注

### 4. 日闭环研判
预留并在收到回答后更新/填写：
- 活动ID/能力点
- 独立稳定 / 独立较慢 / 提示后会 / 实物后会 / 换情境不会 / 未掌握 / 可上探
- 证据（UU关键回答）
- 下一学习日处理
- 是否进入间隔复习链

## 七天学习计划Excel
至少包含：
1. 本周总览
2. 上周继承与本周变化
3. 七天详细课程
4. 复习链
5. 惊喜挑战/前沿拓展
6. 家长记录
7. 周测
8. 下周决策
9. E审查摘要

七天详细课程采用与单日“今日详细课表”相同的核心字段。

## 可读性
- 冻结表头
- 自动换行
- 文本型列宽以可读为优先
- 家长话术和题目不要被截断
- 明确标识必做/可选/挑战
- 测试版与正式版必须视觉上容易区分


## 周测与下周决策工作表
周测必须记录：题目类型、原题/变式、UU回答、是否独立、是否能解释、是否迁移。

下周决策至少记录：
- 能力点
- 本周状态
- 证据
- 下周处理（升级/变式复习/降难补强/低频回访）
- 下一次复习节点
