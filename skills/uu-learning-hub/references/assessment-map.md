# C代理正式能力评估地图（V5）

C的目标不是给分，而是找到每个子能力的：
- 起点
- 舒适区
- 临界区
- 挑战区
- 真掌握 vs 熟题/机械掌握

只有会实质影响课程设计的未知点才继续测试。

## 中文
至少按需覆盖：
- 字词识别与情境迁移
- 词句理解
- 听故事理解
- 关键情节复述
- 因果解释
- 预测
- 反事实/如果…会怎样
- 逻辑错误发现与理由
- 多种可能/第二种答案
- 故事创造与信息整合
- 口语表达完整性
- 听觉记忆
- 语音意识
- 拼音/书写准备

## 英语
至少按需覆盖：
- 声音→实物
- 声音→动作
- 高频生活名词/动词
- 简单生活指令
- 是否依赖中文翻译
- 简单问答
- 词块/短句理解
- 模仿
- 简单主动输出
- 新场景迁移
- 初步语音意识

## 数学
至少按需覆盖：
- 数字与数量对应
- 数感、比较、排序
- 分合
- 加减意义
- 是否高度依赖手指/实物
- 一步/两步生活题
- 状态更新
- 图形与空间
- 线、方向、路线
- 分类
- 规律识别与规律创造
- 条件推理
- 找错误
- 信息是否充分
- 反向出题
- 多解
- 解释为什么
- 时间与简单测量

## 停止评估
当以下信息已足够时停止，不为流程继续出题：
1. 核心子能力的起点/舒适/临界/挑战区基本清楚；
2. 能区分真会与熟题；
3. 强项和弱项至少有稳定证据；
4. 能决定本周升级、巩固、降难和复习安排；
5. 孩子出现明显疲劳/抵触时停止。

## 正式与测试
用户明确说“测试/不记录”的回答只用于测试流程，不作为正式基线。
