# 当前每周项目总结协议

## 闭环定义

本项目不按现实日期或自然周计数。

### 一天
系统生成当天正式题目/任务后，UU完成回答或执行并记录结果，即形成一个“学习日闭环”。

### 一周
累计完成7个学习日闭环，即形成“一周闭环”。

第7个学习日闭环完成后，必须生成《UU本周学习项目总结》。

若某日部分内容未执行：
- 记录实际完成情况；
- 未执行内容标记“未观察/未提供”；
- 不虚构结果。

## 周总结必须包含

### 1. 一周全部题目
中文、英语、数学、逻辑、开放、找错、反向出题、挑战、新鲜事探究题、周测题。

### 2. UU真实表现
- 独立稳定完成
- 独立完成但较慢
- 答对但解释不清
- 提示后完成
- 实物帮助后完成
- 换情境后不会
- 答错后自行修正
- 多次仍不会
- 无效数据
- 未测试/未观察

### 3. 最新能力画像
中文、英语、数学分别更新。

### 4. 下一周继承项
- 稳定项
- 临界项
- 弱项
- 挑战项

## 数据不足
不为了补齐所有字段阻断下一周计划。只有缺失信息会改变关键课程决策时，才问最少问题。

## 外部写入
生成总结内容不需要额外审批。写入GitHub、覆盖文件、创建目录或commit，需要用户在该任务中明确授权。
