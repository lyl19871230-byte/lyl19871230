# uu-learning-hub V3 Changelog

相对V2：

1. 新增标准根级 `SKILL.md` 作为唯一当前执行入口；
2. 新增标准 `AGENTS.md`；
3. V1/V2继续冻结为历史档案；V3以后快照不再使用可注册的 `SKILL.md` 文件名；
4. 增加自主执行原则：信息足够时直接推进，不为流程重复确认；
5. 无真实子代理时自动单Agent串行执行相同角色；
6. “必须评估”改为“必须先做能力充分性检查”；
7. 多代理改为按模式选择角色；
8. references改为按模式加载；
9. 来源缓存失败自动降级到原始项目文件；
10. E单项支持N/A，最终仍只PASS/REVISE；
11. 弱项规则改为“必须处理”，允许继续/降级/换表征/暂缓说明；
12. 英语生活化不再等于每周强制新增词句；
13. 明确外部持久化写入需要用户当前任务授权；
14. 明确学习闭环：完成1个正式学习日回答即算1天，累计7天即算1周，与现实日期无关；
15. 第7个学习日闭环后必须生成周总结。
