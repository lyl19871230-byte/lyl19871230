# AGENTS.md — 悠悠学习项目执行规则

## 作用域

本文件适用于 `skills/uu-learning-hub/` 当前正式Skill及其运行资料。

当前可执行入口只有：

`skills/uu-learning-hub/SKILL.md`

`v1/` 与 `v2/` 为历史冻结档案，不作为当前执行入口。V3及以后历史快照使用 `SKILL.snapshot.md`，避免重复注册Skill。

## 自主执行原则

1. 已有信息足以安全、合理推进时，直接继续执行，不为了流程确认已知事实。
2. 只有缺失信息会实质改变课程难度、事实正确性、安全结果或外部持久化写入时才提问。
3. 能标记为“未知/待观察”而继续完成任务的，不应阻断任务。
4. 不要求用户重复提供已经存在于当前项目、正式能力画像、周总结或来源文件中的信息。
5. 某个非关键数据源、缓存或子代理不可用时，优先降级执行并简要标记限制；只有缺失内容使结论无法可靠完成时才停止。

## 多代理与降级

七天计划默认角色链：

**C → A → B → D → F → E → Controller**

- 环境支持真实子代理：优先实际委派。
- 环境不支持真实子代理：主Agent按相同职责串行执行，不再向用户确认。
- 不得声称运行了不存在的独立代理。
- 用户明确写“无需多代理即可”时，直接使用单Agent完成当前模式。

新鲜事默认：**B → F → E-lite**  
推荐默认：**C-lite（必要时）→ B → E-lite**

不要把完整七天计划链强加给轻量任务。

## 澄清原则

### 必须提问
仅当缺失信息会直接改变：
- 课程难度或安全性；
- 正式能力研判；
- 用户选择的资源类别/关键限制；
- 外部持久化写操作；
- 无法可靠判断的关键事实。

### 不应提问
- 只是为了“走流程”；
- 已有正式数据已经足够；
- 缺失项可标记未知并继续；
- 某个缓存失败但原始来源仍可读取；
- 没有真实子代理但主Agent可以串行执行。

## 审批边界

### 必须保留的审批要求
下列动作属于外部持久化写操作，需要用户在当前任务中明确授权：
- 写入/修改GitHub；
- 覆盖或删除外部文件；
- 创建commit；
- 其他会持久改变外部系统状态的操作。

生成课程、总结、能力画像、建议、Excel内容本身不需要额外审批；用户已经请求生成时，应完成任务，不在中途反复确认。

## 能力评估

正式七天计划必须先由C做“能力充分性检查”，不是机械要求重新提问。

- 当前正式数据足够：直接继续。
- 少量关键未知：只问最少问题。
- 无可靠正式数据：做自适应评估。
- 用户明确说“测试/不记录”的数据不得进入正式画像。

## 来源与证据

B默认：
1. 查最新来源原始资料缓存；
2. 缓存失败则自动回原始项目文件；
3. 精确数字、图表、原话、OCR异常、来源冲突时必须回原文件；
4. 时间敏感“新鲜事”必须查近期可靠公开来源。

原始文件始终高于OCR缓存。

## 七天课程连续性

上一周弱项必须被“处理”，处理可以是：
- 继续训练；
- 降级训练；
- 换表征训练；
- 暂缓并写明理由。

不得无理由消失。

稳定项应合理降频或升级；临界项应变式复现；挑战项继续上探。

## 一天与一周

本项目按学习闭环计数，不按现实日期：

- 一天：当天正式题目/任务已生成，UU完成回答或执行并记录结果。
- 一周：累计完成7个学习日闭环。
- 第7个学习日闭环后必须生成本周项目总结。

现实日期、星期几、是否跨自然周都不影响闭环计数。

## 每周总结

一周闭环后生成《UU本周学习项目总结》，至少包含：
- 一周全部题目；
- UU关键回答；
- 会/不会/提示后会/换情境不会/可上探；
- 三科最新能力画像；
- 稳定项、临界项、弱项、挑战项；
- 下一周继承项。

下一周C/D/E必须优先读取上一周总结。

若部分数据缺失：
- 标记“未观察/未提供”；
- 不虚构；
- 不为了补齐所有字段阻塞下一周任务；
- 只在缺失信息会改变下一周关键决策时问最少问题。

## E审查

E单项可以标记 `N/A`，最终只输出：
- PASS
- REVISE

只有“适用且关键”的审查项失败时才REVISE。

E必须重点检查：
- 连续性
- 系统性
- 题目逻辑
- 表述清晰
- 英语生活化
- 难度
- 真假掌握
- 家长可执行性
- 上周继承
- 周目标可验证

## 英语

英语生活化不等于每周强制加新词新句。可以复用已学表达并提高理解、迁移和主动使用。不得为了满足形式要求增加超负荷的新内容。

## 任务完成原则

用户请求正式交付物时，只要安全、事实和关键输入足够，就应尽可能一次完成。

推荐的降级链：
- 来源缓存不可用 → 原始来源
- 子代理不可用 → 单Agent串行角色
- 上周总结不完整 → 已有正式画像 + 最少量复测
- 个别来源不可读 → 其他可靠来源 + 明确限制

不要把可恢复的工具问题变成用户必须解决的问题。
