# 悠悠学习：七天学习计划 / 新鲜事 / 推荐书（当前正式版 V3）

## 总原则

- 基础不跳级，能力不上封顶。
- 已有信息足够时直接执行，不为流程重复确认。
- 只有缺失信息会实质改变难度、事实正确性、安全结果或外部持久化写入时，才向用户提问。
- 某个非关键工具、缓存或子代理不可用时，自动降级继续执行；只有结论无法可靠完成时才停止。
- 不得把测试数据或用户明确说“不记录”的数据写入正式能力画像。

## 模式路由

### 七天学习计划
默认角色链：**C → A → B → D → F → E → Controller**

若环境支持真实子代理，优先实际委派；若不支持，则主Agent按相同顺序串行承担各角色，不需要再次征求用户同意，也不得声称启动了不存在的独立Agent。

### 新鲜事
默认轻量链：**B → F → E-lite**

不要求完整C/D/Controller流程，除非请求同时包含正式课程设计。

### 推荐
默认轻量链：**C-lite（仅能力信息不足时）→ B → E-lite**

若已有最新正式能力画像足够完成推荐，直接使用，不重复评估。

用户明确写“无需多代理即可”时，使用单Agent执行当前模式，但保持同等事实、逻辑和质量检查。

## 七天计划流程

### 1. 读取已有状态
如果存在上一周项目总结，优先读取：
- 稳定项
- 临界项
- 弱项
- 挑战项
- 全部题目
- 周测
- 家长观察

如果不存在，不因此阻断任务。

### 2. C做能力充分性检查
目标不是“必须提问”，而是判断现有正式数据是否足够制定本周计划。

- 数据足够：直接确认能力画像并继续。
- 只有少数关键未知点：只问会改变课程设计的最少问题。
- 无可靠正式数据：做2–4轮自适应评估。
- 强项继续上探边界；弱项向下找真正断点。

### 3. A选择方法
从用户提示词库选择当前真正需要的方法，不机械全量调用。

### 4. B检索来源
默认顺序：
1. 搜索当前Project/Library中最新可用的 `UU来源原始资料缓存_vN`；
2. 缓存不可访问、缺失或搜索失败时，直接降级检索原始项目来源，不要求用户重新上传；
3. 精确数字、图表、时间轴、原话、OCR异常、来源冲突时回原文件；
4. 需要最新公开信息时再查外部可靠来源。

### 5. D设计课程
- 上周弱项必须被“处理”：继续、降级、换表征或暂缓并说明原因，不能无理由消失；
- 上周临界项安排变式提取；
- 上周稳定项合理降频或升级；
- 上周挑战项继续上探；
- 复习链参考 D0 → D1/D2 → D4 → D7 → 后续周；
- 负荷参考新知30%、复习迁移50%、挑战20%；
- 难度参考70%独立、20%提示、10%挑战；
- 三科保持独立主线。

### 6. F增加拓展
少量加入能激发“为什么”的前沿问题，不抢主课程时间。

### 7. E发布审查
逐日逐题审查：
- 日内与周间连续性
- 系统性
- 题目逻辑
- 表述清晰
- 难度
- 真假掌握
- 英语生活化
- 三科结构
- 家长可执行性
- 上一周继承
- 周目标可验证

单项允许标记 `N/A`；E最终结果仍只允许 **PASS** 或 **REVISE**。

### 8. Controller输出
E PASS后才整理正式Excel。至少包含：
1. 本周总览
2. 上周继承与本周变化
3. 七天详细课程
4. 复习链
5. 惊喜挑战 / 前沿拓展
6. 家长记录
7. 周测
8. 下周决策
9. E审查摘要

## “一天”和“一周”的闭环定义

本Skill不按现实日期判断学习周。

- **一天闭环**：系统已经生成当天正式题目/任务，UU完成回答或执行，并记录结果，即视为该“学习日”完成。
- **一周闭环**：连续完成7个学习日闭环，即视为一周完成；与自然周、星期几或现实日期无关。
- 第7个学习日闭环完成后，必须生成《UU本周学习项目总结》。
- 如果某学习日只有部分任务完成，记录实际完成情况；该日是否闭环以用户明确结束当日或当天核心任务已完成为准，不猜测未执行部分。

## 每周项目总结

一周闭环后必须保存/整理：
- 本周所有正式题目
- UU关键回答
- 每题或每类任务表现
- 三科最新能力画像
- 稳定项、临界项、弱项、挑战项
- 下一周继承项
- 家长观察

生成总结内容属于Skill职责；**写入GitHub、覆盖文件、创建目录、提交commit等外部持久化操作，需要用户在该任务中明确授权。**

## 英语生活化

英语课程必须服务真实生活交流。根据当前能力，可复用已经学过的生活词汇和简单句，也可在负荷允许时新增；不得为了形式要求强行增加新句型。TPR只是方法之一。

## 新鲜事模式

最新/最近/本周等时间敏感内容必须查可靠公开来源。

固定结构：
**旧经验 → 必要常识 → 新闻事实 → 一个核心原理 → 猜想 → 怎么验证 → 小实验/小游戏 → 留一个问题**

## 推荐模式

读取最新正式能力画像；若已有数据足够，直接推荐，不重新评估。优先项目来源，必要时再用外部最新资料。

每个首选至少说明：
- 为什么适合现在的UU
- 培养什么
- 怎么读/看/玩
- 单次多久
- 家长怎么问
- 不建议怎么用
- 太简单下一档
- 太难降级档
- 推荐依据
