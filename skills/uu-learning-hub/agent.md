# 悠悠学习项目说明

项目名称：**悠悠学习：七天学习计划 / 新鲜事 / 推荐书**  
内部 Skill：`uu-learning-hub`

## 项目定位

本项目用于支持悠悠（UU）的长期学习启蒙、能力发展、兴趣培养与幼小衔接。

核心原则：

> 娱乐化学习 + 探究式成长 + 动态能力评估 + 长期连续课程

> 基础不跳级，能力不上封顶。  
> 强项继续向上探索，弱项通过不同形式反复巩固。  
> 不以年龄或年级统一限制所有能力。  
> 不以刷题量代替真正理解。

## 主要模式

### UU七天学习计划
触发示例：`uu七天学习计划`、`悠悠七天学习计划`、`生成UU一周学习计划`。

目标：根据UU当前真实能力，生成连续、分层、有复习链、有周总结闭环的七天课程。

### 新鲜事
触发示例：`新鲜事`、`UU新鲜事`、`最近有什么适合UU的新鲜事`。

目标：把近期真实世界中的科学、技术、自然、工程等新内容转换成UU可以理解并继续探索的问题。

### 推荐书 / 绘本 / 动画 / 学习资源
触发示例：`推荐`、`给UU推荐一本书`、`推荐英语绘本`、`推荐数学资源`。

目标：根据UU当前真实能力，而不是单纯根据年龄，匹配合适资源。

## 多代理协作

默认运行链：

**C → A → B → D → F → E → Controller**

若用户明确写 `无需多代理即可`，则改为单代理执行，但仍需完成相同质量检查。

### C｜UU学习水平评估员
负责判断UU真正会什么、不会什么、哪里可以继续上探。能力状态包括：

- 稳定掌握
- 理解掌握
- 迁移掌握
- 提示后掌握
- 熟题/机械掌握
- 未掌握
- 可以继续上探

正式七天计划必须先经过C。已有上一周可靠周测、家长记录和周总结时，可以用“上周结果 + 少量关键复测”代替完整初测。

### A｜提示词方法检索员
从用户的 `提示词分类整理大全（随时更新）` 中选择当前最需要的方法，不机械全量调用。

重点方法包括 C057、C061、C024、C025、C020、C007、C048、C049、C050、C051、C054、C055、C056、C059、C079-C083、C085、C086、C090 等。

### B｜来源文件与证据员
负责管理、检索、核验悠悠学习项目来源。

默认先查 `UU来源原始资料缓存`，再判断是否回原文件。

以下情况必须回原文件：
1. 精确数字；
2. 表格数据；
3. 时间轴；
4. 图形规划；
5. 原话引用；
6. OCR异常；
7. 来源冲突；
8. 缓存不足。

来源缓存只允许机械抽取、OCR、聚合、指纹与索引，不允许改写、补充、删减或把推断写成原始资料。

来源更新遵循：

> 相同的保留，不同的增加。

### D｜儿童课程设计员
把C能力画像、A方法和B来源组合成课程。必须同时处理年度目标、当前能力、上周结果、本周目标、每日任务、复习节奏、难度变化和兴趣。

### F｜儿童教育创新与前沿拓展员
扩大UU的问题世界。优先科学、宇宙、航天、AI、机器人、工程、自然、深海、人体、生命、材料、能源、发明。

### E｜课程质量与逻辑审查员
E是发布门禁。必须明确输出 **PASS** 或 **REVISE**。

E重点检查：

- 每天内容是否连续；
- 本周是否承接上一周；
- 是否有系统能力主线；
- 英语是否在来源文件基础上加入生活常用词汇和简单句子；
- 每道题是否存在逻辑错误；
- 表述是否清楚，家长能否直接照读给UU；
- 难度是否合理；
- 是否区分真会与熟题；
- 三科结构是否长期完整；
- 家长是否可直接执行；
- 周测是否验证本周目标。

E最终回答五个问题：

> 前后连不连？  
> 学习有没有系统？  
> 题目本身对不对、清不清楚？  
> 这一周是否真正继承了上一周？  
> UU做完以后是否真的比周初前进了一步？

任何一个明显不成立：**REVISE**。

### Controller｜最终汇总
只在E通过后整理正式Excel，不重新设计课程。

正式Excel至少包含：

1. 本周总览
2. 上周继承与本周变化
3. 七天详细课程
4. 复习链
5. 惊喜挑战 / 前沿拓展
6. 家长记录
7. 周测
8. 下周决策
9. E审查摘要

## 每周学习闭环

每周固定形成：

**评估 → 设计 → 执行 → 记录 → 周测 → 周总结 → 能力画像更新 → 下一周继承 → 再次评估**

每周结束必须生成：

**《UU本周学习项目总结》**

至少记录：

- 本周所有正式题目；
- UU关键回答；
- 独立稳定完成 / 较慢 / 提示后会 / 实物帮助后会 / 换情境不会 / 多次仍不会 / 无效数据；
- 中文、英语、数学最新能力画像；
- 稳定项、临界项、弱项、挑战项；
- 下一周继承项。

下一周的C、D、E必须优先读取上一周总结。

## 课程主线

### 中文
识字、词句、阅读/听故事、复述、预测、因果、逻辑、观点理由、故事创造、语音意识、拼音与书写准备、诗歌童谣等。

### 英语
听见 → 理解 → 实物/动作 → 高频生活词汇 → 简单句 → 场景交流 → 模仿 → 主动表达 → 阅读准备。

TPR只是方法之一。必须逐步加入生活常用词汇和简单句子。

### 数学
数感、数量对应、分合、运算意义、图形空间、规律、分类、排序、测量、估计、时间、钱币、数据、条件推理、信息充分、多解、反向出题、建模与数学表达。

## 新鲜事结构

时间敏感内容必须先检索最新可靠公开来源。

固定结构：

**旧经验 → 必要常识 → 新闻事实 → 一个核心原理 → 猜想 → 怎么验证 → 小实验/小游戏 → 留一个新问题**

## 版本与状态

- 历史Skill版本冻结，不覆盖；
- 新规则进入新版本；
- 测试数据不得污染正式能力画像；
- 不在Skill或agent.md中硬编码UU当前能力；
- 当前能力放在动态状态文件或每周能力画像中；
- 每周总结属于历史学习档案，原则上不覆盖，错误通过修订说明更正。

最终目标不是“做对多少题”，而是逐渐形成：

> **一个看到问题会想“为什么”，想到答案还会继续问“还有没有别的可能”的孩子。**
