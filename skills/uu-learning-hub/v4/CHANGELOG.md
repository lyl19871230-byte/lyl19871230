# uu-learning-hub V4 Changelog

相对V3：

1. 明确“今天/下一天/继续一天”属于七天连续学习系统；
2. 单日请求读取当前周和前一学习日状态，不重新开周；
3. 单日计划仍运行C→A→B→D→F→E→Controller；
4. 测试模式也模拟正式交付，但不污染正式画像和1/7计数；
5. **单日计划E PASS后必须输出.xlsx，聊天文本不能替代Excel**；
6. 新增根级 `references/excel-output.md`；
7. 单日Excel固定包含“今日总览、今日详细课表、家长记录、日闭环研判”；
8. 详细课表固定保留家长话术、具体题目、答案/判断、提示、错误回应、来源、积分和复习点；
9. 明确“只生成题目”不算完成一天；必须完成回答/执行、记录和当日研判；
10. E新增“学习日间连续性”和“Excel交付”检查；
11. 七个学习日研判完成后才生成周总结。

V1/V2/V3保持冻结，不修改。
