# 悠悠学习系统 V6：先评估、再画像、再课程

## 0. 核心原则
- 基础不跳级，能力不上封顶。
- 每周先做充分评估，再生成正式能力画像，再据画像出题。
- 能力点可以连续，题型必须多样；不得把“换数字/换动物/加一个条件”当成题型多样性。
- 稳定项降频，临界项变式复习，弱项换表征修复，强项立即上探。
- 中文识字量与英语词汇量是显性积累目标，不得被逻辑/探究训练替代。
- 测试数据不得进入正式能力画像。
- 未观察的数据必须写“未观察/未提供”，不得猜测。

## 1. 周流程（强制）
每个新学习周按以下顺序执行：

**W0 周前/第一天充分评估 → P 能力画像 → A 方法选择 → B 来源核验 → D 课程设计 → F 新鲜事 → E 发布门禁 → Controller 输出**

### W0 周前充分评估
- 每周第一天先做充分能力评估；建议总时长约20–30分钟，可分两段。
- 评估必须覆盖中文、英语、数学、学习品质；题型要高信息量且多样。
- 记录不只“对/错”，还要记录：独立稳定、独立但慢、答对但解释不足、提示后完成、实物/动作后完成、换情境不会、自我修正、疲劳/拒绝、未观察。
- 评估后才允许形成当周正式能力画像与课程起点。
- 详细规则见 `references/weekly-assessment.md`。

### P 能力画像
至少输出：
- 中文：识字稳定度、听说/复述、因果/反事实、表达、逻辑与阅读理解准备。
- 英语：听觉词汇、生活指令、问句理解、主动输出、短时保持、两步任务。
- 数学：数感/分合、数量变化、反向建模、空间、规律、信息充分性、时间、估计、统计等。
- 学习品质：专注、两步指令、自我修正、任务完成、主动提问。
- 每项标记：稳定 / 临界 / 提示后会 / 未掌握 / 可上探 / 未观察。

## 2. 中文主线（每天强制）
中文每天同时存在两条子线：

### A. 识字积累线
- 每天必须有识字内容，不能被表达/逻辑题挤掉。
- 识字路径优先：字 → 词 → 句 → 新情境/绘本/环境文字 → 延迟提取。
- 新增字数依据上一轮反馈动态调整；掌握好要及时新增，不能长期只复习。
- 一次认对不算稳定，必须通过随机提取、换词/换句、延迟提取或新情境验真。

### B. 语言与思维线
轮换使用：
- 复述、概括、排序重建、预测、反事实、因果、证据、采访、角色辩论、禁词描述、故事创造、给标题、纠错、换视角、谜语/童谣等。
- 不能连续多天都是“听题→口答→解释”。

## 3. 英语主线（每天硬门槛）
### 每日最低覆盖
- 至少 **5个核心词**。
- 至少 **2个适龄简单句**。
- 5词不等于5个全新词；新词/复习词比例必须根据最近反馈动态调整。

### 动态新增规则
- 5词中4–5个稳定，句子也稳：通常可 3新+2旧，或在负荷允许时更快推进。
- 约3个稳定：通常 2新+3旧。
- 1–2个稳定：通常 1新+4旧。
- 大量依赖动作/提示：0–1新+4–5旧，先修复理解。
- 全部轻松且能主动输出：不得因“复习”拖慢进度，应及时加新词/新组合。

### 英语不是单词表
- 词必须进入真实生活句、问答、角色扮演、家庭任务。
- TPR只是方法之一。
- 自然重述纠错，不讲抽象语法。
- 题型轮换：寻宝、商店、真假动作、听描述摆场景、选择问答、角色任务、纠错、补句、分类、听声音找物、两步任务等。

## 4. 科学复习与记忆
默认采用简化间隔提取链：
**D0 → D1/D2 → D4 → D7 → 后续低频回访**

要求：
- 每次复习换情境/换说话人/换任务形态，不原样复制。
- 稳定项降频；临界项在D1/D2、D4做变式提取；弱项换实物/图/动作/故事等表征；强项上探。
- 复习链用于中文识字、英语词句、数学核心概念。
- 详细见 `references/review-and-memory.md`。

## 5. 数学与思维
数学不能退化成口算。持续轮换：
- 数感、数量、分合、加减意义
- 比较/分类/排序/规律
- 图形、空间、路线、旋转、对称、积木建构
- 测量、估计、时间、钱币、统计
- 信息充分性、条件推理、无关信息、反例
- 一题多解、反向出题、错误解法侦探、建模

强项通过多条件、多步骤、多解、解释、建模继续上探；弱项回到实物与一步关系。

## 6. 题型多样性硬规则
E审核看的是“认知任务形态”，不是文字表面不同。

可用任务形态包括但不限于：
- 身体移动/寻宝
- 排序重建
- 角色扮演/采访/辩论
- 观察比较
- 找错/反例/真假判断
- 路线/空间建构
- 估计→验证
- 规则创造/规则切换
- 数据记录/投票统计
- 无声动作配音
- 禁词描述
- 盲袋预测
- 实验与模型
- 反向出题

若连续活动仍是“听题→口答→解释”，即使题目文字不同，也判定多样性不足。
详见 `references/task-diversity.md`。

## 7. 来源与扩展
- 项目来源文件决定：能力方向、年龄适配、学习方式、阶段目标、负荷边界。
- 来源文件题型少时，可以进行题型扩展，但必须保留来源要求。
- 必须区分：
  - “来源文件原题/原要求”
  - “基于来源能力方向的扩展设计”
- 不得把自行设计的题冒充来源原题。
- 最新公开事实（如今日新鲜事）才使用外部可靠公开来源。
详见 `references/source-policy.md`。

## 8. 今日新鲜事
结构固定为：
**已有经验 → 基础名词 → 最小必要常识 → 最新事实 → 一个核心原理 → 猜想 → 验证/模型/小游戏 → 留一个问题**

规则：
- 先补基础名词和必要常识，不能直接扔成人新闻。
- “今天/最近”必须查可靠最新来源。
- 儿童只需要掌握适龄核心概念，成人术语不作为记忆目标。
- 领域轮换：宇宙、工程、机器人/AI、自然、深海、人体、材料、能源、发明等。

## 9. E发布门禁（强制）
E必须在发布前逐项审核，最终只有：
- **PASS**
- **REVISE**

关键项任一FAIL，不得发布正式计划：
1. 纵向连续性
2. 系统性进阶
3. 周前评估匹配
4. 中文每日识字主线
5. 英语每日≥5词
6. 英语每日≥2句
7. 英语/中文新增速度不能过慢
8. 间隔复习链
9. 真掌握验真
10. 题型真正多样
11. 来源一致性
12. 适龄负荷
13. 新鲜事先备知识
14. 家长可执行性
15. 每项能力能形成可判断证据

完整E规则见 `references/e-audit-gate.md`。

## 10. 一天/一周闭环
一天完成条件：
**正式任务生成 → UU实际回答/执行 → 记录提示与表现 → 当日研判完成**

一周完成条件：
- 累计7个正式学习日闭环；
- 第7日后生成《UU本周学习项目总结》；
- 汇总稳定项、临界项、弱项、挑战项、复习状态、下周待评估点。

新一周不直接延续难度：先做新的充分评估，再更新能力画像。

## 11. Excel输出
正式学习计划与周前评估优先输出 .xlsx，保持精简、可执行。
不要默认做臃肿多Sheet。
推荐：
- 周前评估：能力评估题 / 家长记录与画像 / E审核
- 单日计划：当天计划 / E审核（必要时）
- 周计划：本周总览 / 七天课程 / 复习链 / 家长记录 / 周测 / E审核

字段优先保留：科目、编号、任务形态、用时、直接给UU的话/玩法、判断能力、答出来→、答不出来→、方法、来源、复习/下一步、UU表现。

## 12. 真实子代理说明
若环境存在真正独立子代理，可将E委派给独立审查角色。
若环境不支持，不得声称“E子代理已独立运行”；应说明按E角色串行审核。
