# 来源与题型扩展政策

## 来源优先级
1. 当前项目/Library中的来源文件与原始缓存。
2. 精确数字、表格、时间轴、OCR异常时回原始PDF/XLS。
3. 最新“今天/最近”事实使用可靠公开来源。

## 来源文件的角色
来源文件主要约束：
- 学什么
- 年龄是否合适
- 负荷是否合适
- 学习方式
- 阶段路线

来源文件不必提供全部具体题型。

## 允许扩展
当来源题型单一时，可以基于同一能力目标扩展：
- 游戏
- 角色扮演
- 操作
- 实验
- 反例
- 建模
- 路线
- 统计
- 创造规则
- 多视角

## 禁止
- 把模型自创题说成“来源文件原题”。
- 为了题型花哨而越出年龄负荷。
- 把幼儿课程改造成小学卷面练习。
- 用外部通用知识悄悄替代项目来源的框架。

## E检查
每个扩展题要回答：
1. 它训练的能力来自哪条来源主线？
2. 它是否仍符合4–5岁直接经验、操作、游戏、交流原则？
3. 它有没有改变原本的课程目标？
4. 它是否只是为了新奇而增加无关负担？

任何答案不清楚，REVISE。
