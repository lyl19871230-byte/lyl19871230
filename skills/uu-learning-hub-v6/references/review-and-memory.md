# 科学复习与动态新增

## 默认间隔链
D0 → D1/D2 → D4 → D7 → 后续低频回访

## 每次复习必须变式
不要原题重做。可以改变：
- 场景
- 说话人
- 任务形式
- 输入方式
- 输出方式
- 是否有实物
- 是否要求解释/生成

## 四类状态
### 稳定
- 独立
- 能解释
- 换情境仍会
- 延迟仍会
处理：降频，进入更复杂应用。

### 临界
- 独立但慢
- 答对但解释不足
- 换情境不稳
处理：D1/D2、D4变式提取。

### 弱项
- 依赖提示
- 实物/动作后才会
处理：换表征：实物、图、动作、故事、对比；减少新增但保留主线。

### 强项
- 快速稳定
- 能迁移
- 能反向出题
处理：立即上探，不因复习拖慢。

## 英语每日5词动态配比
最低覆盖量固定为5词，但新词数动态：
- 4–5词稳定：通常可2–3新；若长期稳定可更快。
- 约3词稳定：约2新+3旧。
- 1–2词稳定：约1新+4旧。
- 明显依赖提示：0–1新+4–5旧。
- 全部轻松且有主动输出：必须推进。

句子每天至少2句：
- 旧词进入新句
- 新词进入生活句
- 至少一部分句子在真实场景中理解/使用

## 中文识字动态新增
- 稳定字：降频，进入词/句/阅读。
- 临界字：D1/D2、D4随机提取。
- 弱字：换词语、动作、场景、环境文字。
- 掌握好时继续新增，不允许长期只复习旧字。

## 数学复习
不要只换数字。
例如同一“数量关系”可轮换：
- 实物变化
- 错解法法官
- 购物预算
- 盲袋预测
- 反向出题
- 信息筛选
- 数据统计
- 路线/空间模型
