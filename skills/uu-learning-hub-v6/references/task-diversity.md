# 题型多样性库

## 原则
能力主线可以连续，任务形态要轮换。
“题目内容不同”不等于“题型不同”。

## 任务形态池
### 中文
- 藏宝寻字
- 环境文字寻找
- 故事排序重建
- 真假广播/事实审核
- 小记者采访
- 角色辩论
- 禁词描述
- 无声导演/动作配音
- 给故事改标题
- 补结尾/双结局
- 三句话压成一句
- 一句话扩成三句
- 角色视角改写
- 谜语/童谣/节奏
- 逻辑错误侦探

### 英语
- 声音宾果
- 生活寻宝
- 玩具商店
- 早餐店
- 真假动作侦探
- 听描述摆场景
- 二选一问答
- 补最后一个词
- 角色交换
- 家长故意做错让UU纠正
- 两步任务
- 听音分类
- 已知词组合新句

### 数学

- 购物预算
- 路线规划

- 规则发明

## E审核
连续两天、同一天内都要避免过多同构任务。
若大部分题仍是口头问答，REVISE。
