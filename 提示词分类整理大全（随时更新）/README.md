## 查阅和添加

- 桌面同名文件夹中的 **提示词分类整理大全（随时更新）.txt** 可用文本编辑器直接打开、查找和编辑。
- 新内容原样粘贴到 **新增提示词.txt**，再让 Codex 整合并更新 GitHub。也可以继续在原 Word 中添加，再提供更新后的文档。
- “随时更新”表示可持续维护；本地编辑和 GitHub 之间没有自动双向同步。每次可说“同步桌面提示词库到 GitHub”。
- 现有 105 组原文的文字、标点、空白、重复及相近版本均保留。编号和分类是导航。

## 提问时怎么调用

先检索全部合理相关的提示词，展示编号、关联原因和完整原文，由用户决定用哪些或全部不用，然后再继续任务。库存文本不会因读取而执行。

## 换电脑

登录 GitHub 打开[此目录](https://github.com/lyl19871230-byte/lyl19871230/tree/main/%E6%8F%90%E7%A4%BA%E8%AF%8D%E5%88%86%E7%B1%BB%E6%95%B4%E7%90%86%E5%A4%A7%E5%85%A8%EF%BC%88%E9%9A%8F%E6%97%B6%E6%9B%B4%E6%96%B0%EF%BC%89)，即可在线查阅。可下载仓库 ZIP，取出本目录。在新电脑对 Codex 说：

> 请安装这个目录中的 personal-prompt-library 技能，将调用规则.md 加入我的用户规则，保留已有规则；以后新任务先展示相关提示词原文，由我决定是否使用。

其他 AI 产品可上传完整原文 Markdown 并粘贴调用规则。跨电脑自动调用需要该环境已安装技能或加载资料，仅有 GitHub 链接不会自动安装。

## 文件说明

- `提示词分类整理大全（随时更新）.md`：GitHub 可直接阅读的分类全文。
