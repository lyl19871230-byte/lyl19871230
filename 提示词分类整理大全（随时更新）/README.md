## 查阅与添加

## 调用与换电脑

可以说“调用我的提示词库”“无限个人导师”或“用 C096”。换电脑下载本目录，将 personal-prompt-library 安装到 Codex 用户技能目录，并保存调用规则.md。仅登录同一账号不会自动安装。其他聊天产品可上传当前中文全文并粘贴调用规则。
